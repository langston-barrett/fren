A clause of a function's contract that mentions other names, but no parameter of its function, nor the function's value (a warning, `contract_mentions_nothing`).

Example:

```fren
pub fn limit(Int): Int

pub fn scale(n: Int): (r: Int) {
    ensure grows: r >= n
    ensure positive: limit(0) > 0
}
```

`positive` says something about `limit`, not about `scale`: it holds or
fails whatever `scale` is applied to. It is probably in the wrong place.
`fren check` also reports the contract as unrealizable (`F0631`): nothing
is known of `limit`, so where `limit(0) <= 0`, no value of `scale`
satisfies `positive`. State the clause in the contract of the function it
is about, or as a global expectation:

```fren
pub fn limit(n: Int): (r: Int) {
    ensure positive: when n = 0, r > 0
}

pub fn scale(n: Int): (r: Int) {
    ensure grows: r >= n
}
```
