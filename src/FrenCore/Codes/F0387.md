A recursive payload written with unsupported nesting or type arguments.

Erroneous code example:

```fren
enum Tree<T> { Leaf(T), Node(Tree<Option<T>>) }
```

A generic enumeration's payload of its own type gives it its own type
parameters, in order. A recursive occurrence within another instance,
as in `Option<Tree<T>>`, is also refused for now. A type parameter may
be an element type of a set, sequence or relation within a payload or
field, as in `enum Bag<T> { Empty, Many(Set<T>) }`.

```fren
enum Tree<T> { Leaf(T), Node(Tree<T>) }
```
