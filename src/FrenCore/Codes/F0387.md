A type parameter written where it may not be.

Erroneous code example:

```fren
enum Bag<T> { Empty, Many(Set<T>) }
```

For now, a generic type's type parameter is a payload's or field's whole
type, or an argument of a generic type, as in `Option<T>`, but not an
element type of a set, relation or sequence. A generic function's type
parameter may be one, as in `fn grow<T>(s: Set<T>, x: T): Set<T>`. And a
generic enumeration's payload of its own type gives it its own type
parameters, in order, as `List<T>` does within `enum List<T> { Nil,
Cons(T, List<T>) }`:

```fren
enum Bag<T> { Empty, One(T) }
```
