A `set_option fren.evidence` before something that has no checks to test.

Erroneous code example:

```fren
proc c(x?): (y?) {
  set_option fren.evidence "random" in
  ensure r: y? iff x?
}
```

A guarantee is not itself checked: the checks of a procedure are about
its expectations, calls, `det` outputs and the procedure as a whole, so
the setting goes before one of those, or before the procedure.

```fren
set_option fren.evidence "random" in
proc c(x?): (y?) {
  ensure r: y? iff x?
}
```

Before a function or a constant, `fren.evidence` can be set only to
`"solver"`: the checks of a function's body or contract, and of a
constant's value, are always the solver's, so another value would be
ignored. It is an error rather than a setting that sets nothing (see
`Reqs/Methods`, "What runs today"):

```text
set_option fren.evidence "random" in
pub fn next(x: Int): Int := x + 1
```

Remove the setting, or put it before the procedures that apply the
function.
