Checks that the method their evidence sets does not run.

Example:

```fren
set_option fren.evidence "random" in
proc c(x: Int): (big?) { ensure r: when x > 0, big? }
```

Not every method can run every check (see `Reqs/Methods`, "What runs
today"). Random testing searches for counterexamples, so it does not run
the checks that need a witness: here the vacuity of `r`'s trigger, and the
redundancy of `r`. Nothing runs them, and that is reported, as
information, with the reason. The solver, or here enumeration, runs them:

```fren
set_option fren.evidence "enumerated" in
proc c(x: Int): (big?) { ensure r: when x > 0, big? }
```
