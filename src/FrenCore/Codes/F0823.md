A function parameter to which every application gives the same function (`needless_higher_order`, allowed by default).

Example:

```fren
set_option fren.lint.needless_higher_order "warn"

fn step(f: fn(Int) -> Int, x: Int): Int := f(x) + 1

proc c(k: Int): (m: Int) { ensure r: m = step(|y| 2 * y, k) + step(|y| 2 * y, k + 1) }
```

The function is private, and every application in its file gives the
parameter the same closure, which mentions nothing of where it is written.
Write it in the function's body, and remove the parameter:

```fren
fn step(x: Int): Int := 2 * x + 1

proc c(k: Int): (m: Int) { ensure r: m = step(k) + step(k + 1) }
```
