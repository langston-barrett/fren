A name is imported twice, or imported and also defined, in the same module.

Erroneous code example:

```fren
mod a
pub enum Shown { S }

mod b
use a::Shown
use a::Shown
```

A `use` brings a name into the module's namespace, which holds each name
once. Remove the duplicate `use`, or rename the item that clashes with it.

```fren
mod a
pub enum Shown { S }

mod b
use a::Shown
```
