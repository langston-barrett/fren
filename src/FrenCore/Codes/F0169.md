`assume` where a procedure's or a function's precondition is written.

Erroneous code example:

```fren
proc halve(x: Int): (y: Int) {
    assume even: x mod 2 = 0
    ensure r: 2 * y = x
}
```

A procedure's or a function's precondition, which constrains its inputs,
is written `require n: e`. `assume` starts a global expectation's
assumptions only; in a procedure's or a function's block, a precondition
is written `require`, with the same meaning:

```fren
proc halve(x: Int): (y: Int) {
    require even: x mod 2 = 0
    ensure r: 2 * y = x
}
```

`fren fix` does not apply this fix, as it applies no fix of a static
error. To rewrite every such `assume` of a directory's `.fren` files and
of the Fren in its Markdown, run `scripts/migrations/assume_to_require.py`
of Fren's repository on the directory.
