Testing found no outputs for an input (a warning).

Erroneous code example:

```fren
proc c(x: Int): (y: Int) {
  ensure above: y > x
  ensure below: y < x
}
```

`fren quickcheck` chose an input that the assumptions allow, and behaviours
of the calls, but its search found no outputs that satisfy the
guarantees. The search tries only some values, so outputs may still
exist: run `fren check`, whose realizability check decides it. Where the
search tries every value of every output, because each is defined or of
a type such as `Bool` whose values it tries in full, no output exists, and
testing reports `F0601` instead. Here no `y`
is both above and below `x`, so `fren check` reports `F0601`. Weaken one
of the guarantees:

```fren
proc c(x: Int): (y: Int) {
  ensure above: y > x
}
```
