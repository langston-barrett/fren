A check that rests on a check that did not pass, which leaves it inconclusive (a warning).

Erroneous code example:

```fren
proc never(x: Int): (y: Int) { ensure r: y > 0 and y < 0 }

proc caller(x: Int): (z: Int) {
    call c := never(x)
    ensure q: z = c.y
    expect wrong: z = 5
}
```

`never` has no outputs, so its realizability fails (`F0601`). Every proof
from `caller`'s hypotheses, which include `c`'s constraints, then holds
vacuously: `wrong` would pass although it is false. So a check that rests on
one that did not pass is not a pass: it is inconclusive (see
`Reqs/Evidence`). Make the check it rests on pass:

```fren
proc never(x: Int): (y: Int) { ensure r: y > 0 }

proc caller(x: Int): (z: Int) {
    call c := never(x)
    ensure q: z = c.y
    expect positive: z > 0
}
```
