A procedure with too many behaviours to enumerate.

Erroneous code example:

```fren
type FirstPercent = n: Int where invariant: n is 0..=99
type SecondPercent = n: Int where invariant: n is 0..=99
type ThirdPercent = n: Int where invariant: n is 0..=99
set_option fren.evidence "enumerated" in
proc c(a: FirstPercent, b: SecondPercent, d: ThirdPercent): (det sum: Int) {
  out sum := a + b + d
  expect e: sum >= 0
}
```

Enumeration searches every assignment of the procedure's variables up to
the size bound, smallest first (see `Reqs/Check`, "Checking by
enumeration"). The number of assignments is the product of each
variable's number of values, and of a second copy's where determinism is
enumerated; here a million. Above 65,536 none of the procedure's checks set
to enumeration is run. So it is where a quantifier ranges over a type with
more than 65,536 values up to the bound. Narrow the types, lower
`fren.enumeration.size`, or have the solver check it:

```fren
type LeftPercent = n: Int where invariant: n is 0..=99
type MiddlePercent = n: Int where invariant: n is 0..=99
type RightPercent = n: Int where invariant: n is 0..=99
proc c(a: LeftPercent, b: MiddlePercent, d: RightPercent): (det sum: Int) {
  out sum := a + b + d
  expect e: sum >= 0
}
```
