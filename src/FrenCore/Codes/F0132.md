A comma is missing after the binders of a quantifier.

Erroneous code example:

```fren
enum Mode { Off, Heat }
proc c(x: Mode): (ok?) { ensure r: ok? iff (exists (m: Mode) m = x) }
```

The binders of `forall` and `exists` end with a comma, before the body.
Add one.

```fren
enum Mode { Off, Heat }
proc c(x: Mode): (ok?) { ensure r: ok? iff (exists (m: Mode), m = x) }
```
