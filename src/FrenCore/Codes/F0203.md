An enum has no variant of that name.

Erroneous code example:

```fren
enum Mode { Off, Heat }
proc c(m: Mode): (on?) { ensure r: on? iff m = Mode::Cool }
```

The message lists the enum's variants. Check the spelling, or add the
variant to the enum.

```fren
enum Mode { Off, Heat, Cool }
proc c(m: Mode): (on?) { ensure r: on? iff m = Mode::Cool }
```
