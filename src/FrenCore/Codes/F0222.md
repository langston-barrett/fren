A trait has a member that is not a method, a law or an expectation.

Erroneous code example:

```fren
trait Counter {
    fn count(Self): Int
    const START: Int := 0
}
```

A trait's members are its methods, which are functions without a body,
its laws and its expectations. Any other item, such as a constant, a
procedure or a type, is declared outside the trait, in its module. A
member is not written `pub`, since it is visible where the trait is, and
for now a method has no body and no type parameters, and no member's block
has a `use`. Move the item out of the trait:

```fren
const START: Int := 0

trait Counter {
    fn count(Self): Int
}
```
