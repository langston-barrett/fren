A code block of a Markdown spec whose info string looks like `fren` but is
not.

Erroneous code example, a Markdown spec:

````markdown
# Climate control

```fren,ignore
pub proc heating(cold?): (heat?) {
    ensure rule: heat? iff cold?
}
```
````

Fren reads the blocks whose info string is exactly `fren`, which are part
of the spec, and those whose info string is exactly `fren example`, which
are examples of the reference, each checked on its own. Every other block
is prose, so the procedure above is not part of the spec, and nothing
checks it. Write `fren` to make the block part of the spec, `fren example`
for an example of the reference, or another language, such as `text`, to
show code that is not checked:

````markdown
# Climate control

```fren
pub proc heating(cold?): (heat?) {
    ensure rule: heat? iff cold?
}
```
````
