A guard of a `match` arm that is the literal `true` or `false` (a warning, `trivial_guard`).

Example:

```fren
enum Shape { Circle(Int), Empty }

proc c(s: Shape): (m: Int) { ensure r: m = match s { Shape::Circle(x) if true => x, _ => 0 } }
```

An arm whose guard is `true` is taken wherever its pattern matches, as
without the guard, and one whose guard is `false` is never taken. `fren
fix` can fix this, removing the guard `true` and the arm whose guard is
`false`, where the `match` without them is still accepted:

```fren
enum Shape { Circle(Int), Empty }

proc c(s: Shape): (m: Int) { ensure r: m = match s { Shape::Circle(x) => x, _ => 0 } }
```
