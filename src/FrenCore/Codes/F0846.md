A private procedure with no results, whose members a global expectation accepts, and which nothing in its file names (`proc_without_outputs`, allowed by default).

Example:

```fren
set_option fren.lint.proc_without_outputs "warn"

pub proc band(temp: Int): (cold?) { ensure rule: cold? iff temp < 18 }

proc colder_is_cold(a: Int, b: Int) {
    assume sorted: a <= b
    call x := band(a)
    call y := band(b)
    expect colder: when y.cold?, x.cold?
}
```

The procedure constrains nothing: it has no outputs for its members to
constrain, so all it does is claim something of its parameters. That is a
global expectation, which means the same and checks each claim the same,
but is not traced as a procedure, and does not ask whether its assumptions
are redundant. `fren fix` can fix this:

```fren
set_option fren.lint.proc_without_outputs "warn"

pub proc band(temp: Int): (cold?) { ensure rule: cold? iff temp < 18 }

expect colder_is_cold(a: Int, b: Int) {
    assume sorted: a <= b
    call x := band(a)
    call y := band(b)
    expect colder: when y.cold?, x.cold?
}
```
