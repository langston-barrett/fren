A `match` whose arms are disjoint, which a table over a scrutinee writes (`match_could_be_table`, allowed by default).

Example:

```fren
set_option fren.lint.match_could_be_table "warn"

enum Shape { Circle(Int), Square(Int), Empty }

proc c(s: Shape): (m: Int) { ensure r: m = match s { Shape::Circle(_) => 1, Shape::Square(_) => 2, _ => 0 } }
```

No two arms match a value in common, but for the last `_`, so the order
of the arms does not matter. A table over a scrutinee states that, and has
it checked. `fren fix` can fix this, writing `table` in place of `match`:

```fren
enum Shape { Circle(Int), Square(Int), Empty }

proc c(s: Shape): (m: Int) { ensure r: m = table s { Shape::Circle(_) => 1, Shape::Square(_) => 2, _ => 0 } }
```
