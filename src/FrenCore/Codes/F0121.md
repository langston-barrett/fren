`<-`, which is one token, as in Lean.

Erroneous code example:

```fren
proc c(x: Int): (p?) { ensure r: p? iff x <- 1 }
```

Fren is lexed as Lean is, and Lean has a token `<-`, so `x <- 1` is not
`x < -1`. To compare with a negation, write a space between `<` and `-`:

```fren
proc c(x: Int): (p?) { ensure r: p? iff x < -1 }
```
