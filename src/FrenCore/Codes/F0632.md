An uninterpreted function's preconditions contradict each other.

Erroneous code example:

```fren
fn rate(n: Int): (r: Int) {
    require positive: n > 0
    require negative: n < 0
    ensure bounded: r < n
}
```

No arguments meet the preconditions, so the postconditions say nothing,
and no application of the function can meet its preconditions. Weaken or
remove one of them:

```fren
fn rate(n: Int): (r: Int) {
    require positive: n > 0
    ensure bounded: r < n
}
```
