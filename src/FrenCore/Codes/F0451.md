A `mutual` group contains a member outside the supported signature boundary.

Erroneous code example:

```fren
mutual {
    fn unknown(Int): Int
}
```

Every member must be a defined, monomorphic first-order function without a
contract. Define its body, or move the unsupported function outside the group.

```fren
mutual {
    pub fn identity(x: Int): Int := x
}
```
