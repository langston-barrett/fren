A pass that rests on a check that is not a proof (information).

Example:

```fren
set_option fren.evidence "random" in
proc lookup(x: Int): (y: Int) { ensure r: y = 0 }

proc caller(x: Int): (z: Int) {
    call c := lookup(x)
    ensure q: z = c.y + 1
    expect one: z = 1
}
```

A check whose pass is a proof from hypotheses has the constraints of the
calls among them. Those hold only where the called procedure has outputs,
which its realizability check shows. Here that check is only run by random
testing, so `caller`'s checks pass with no stronger evidence: each is
counted among the passes by random testing, and named in this message (see
`Reqs/Evidence`). Prove the called procedure realizable with the solver to
make them proofs:

```fren
proc lookup(x: Int): (y: Int) { ensure r: y = 0 }

proc caller(x: Int): (z: Int) {
    call c := lookup(x)
    ensure q: z = c.y + 1
    expect one: z = 1
}
```
