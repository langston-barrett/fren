The type of a closure's parameter, which the function type gives (`redundant_type_annotations`, allowed by default).

Example:

```fren
set_option fren.lint.redundant_type_annotations "warn"

fn twice(f: fn(Int) -> Int, x: Int): Int := f(f(x))

proc c(k: Int): (m: Int) { ensure r: m = twice(|y: Int| y + 1, k) }
```

The parameter has the function type's parameter's type, written in the
signature. `fren fix` can fix this, removing the type:

```fren
fn twice(f: fn(Int) -> Int, x: Int): Int := f(f(x))

proc c(k: Int): (m: Int) { ensure r: m = twice(|y| y + 1, k) }
```
