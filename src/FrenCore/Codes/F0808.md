Two or more arms of a `match` whose bodies are `if`s with the same `else` branch (a warning, `match_arm_if_else`).

Example:

```fren
enum Shape { Circle(Int), Square(Int), Empty }

proc c(s: Shape, k: Int): (m: Int) {
    ensure r: m = match s { Shape::Circle(x) => if x > k then x else 0, Shape::Square(x) => if x < k then 1 else 0, _ => 0 }
}
```

Each condition can be its arm's guard: where it fails, the arms after it
are tried, and a `_` arm gives the `else` branch once. The lint fires only
where every later arm that matches a value of such an arm's pattern has
the `else` branch as its body, so that the value is the same. `fren fix`
can fix this, adding `_ => d` unless the last arm is `_` or a binder with
the body `d`:

```fren
enum Shape { Circle(Int), Square(Int), Empty }

proc c(s: Shape, k: Int): (m: Int) {
    ensure r: m = match s { Shape::Circle(x) if x > k => x, Shape::Square(x) if x < k => 1, _ => 0 }
}
```
