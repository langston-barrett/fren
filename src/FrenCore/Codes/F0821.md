A closure that only applies a function to its parameters (a warning, `redundant_closure`).

Example:

```fren
fn twice(f: fn(Int) -> Int, x: Int): Int := f(f(x))
fn inc(n: Int): Int := n + 1

proc c(k: Int): (m: Int) { ensure r: m = twice(|y| inc(y), k) }
```

The function's name, given for a function parameter, means that closure.
`fren fix` can fix this, writing the name:

```fren
fn twice(f: fn(Int) -> Int, x: Int): Int := f(f(x))
fn inc(n: Int): Int := n + 1

proc c(k: Int): (m: Int) { ensure r: m = twice(inc, k) }
```
