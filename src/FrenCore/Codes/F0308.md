A function or variant is applied to the wrong number of arguments, a pattern has the wrong number of binders, or a match arm has a different number of patterns from its scrutinees.

Erroneous code example:

```fren
type Name
fn arity(Name): Int

proc c(x: Name): (y: Int) { ensure r: y = arity(x, x) }
```

An application gives one argument for each of the function's parameters.

```fren
type Name
fn arity(Name): Int

proc c(x: Name): (y: Int) { ensure r: y = arity(x) }
```
