A guard that compares a binder of its arm's pattern with a literal or a variant, which the pattern can match instead (a warning, `redundant_guards`).

Example:

```fren
enum Shape { Circle(Int), Empty }

proc c(s: Shape): (m: Int) { ensure r: m = match s { Shape::Circle(x) if x = 0 => 1, _ => 2 } }
```

A nested pattern matches exactly the values that the guard lets through.
`fren fix` can fix this, writing the value in place of the binder, and of
its mentions in the arm's body:

```fren
enum Shape { Circle(Int), Empty }

proc c(s: Shape): (m: Int) { ensure r: m = match s { Shape::Circle(0) => 1, _ => 2 } }
```
