A `|` that starts a table's row, or a pattern of one alternative.

Erroneous code example:

```fren
proc c(x: Int): (det y: Int) {
    out y := table {
        | x > 0 => 1,
        | _ => 0,
    }
}
```

Commas separate a table's rows, as they do a `match`'s arms, and the
formatter puts each row on a line of its own, so a row does not start
with `|`. Neither does a pattern of one alternative, in a `match` arm, a
table's arm or a pattern test: only an or-pattern may start with `|`,
which is the separator of its alternatives, so that they line up one per
line. Write the row or the pattern without the `|`:

```fren
proc c(x: Int): (det y: Int) {
    out y := table {
        x > 0 => 1,
        _ => 0,
    }
}
```

```fren
pub enum Sign { Negative, Zero, Positive }

proc c(s: Sign): (det y: Int) {
    out y := match s {
        | Sign::Negative
        | Sign::Zero => 0,
        Sign::Positive => 1,
    }
}
```
