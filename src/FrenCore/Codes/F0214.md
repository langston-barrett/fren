A `set_option fren.evidence` value that does not exist.

Erroneous code example:

```fren
set_option fren.evidence "testing" in
proc c(x?): (det y?) { ensure r: y? iff x? }
```

The evidence of a check is `"random"`, to have it tested on random
behaviours instead of asked of the solver, `"enumerated"`, to have it decided
by enumerating behaviours, smallest first, `"enumerated+random"`, to have it
tested too where enumeration is not complete, or `"solver"`, the default
(see `Reqs/Check`, "Checking by testing" and "Checking by enumeration").
`"tested"` and
`"enumerated+tested"` are the old names of `"random"` and
`"enumerated+random"`, renamed since `tested` is the keyword of a `tested`
claim; they are errors too, and the error's note gives the new name.

```fren
set_option fren.evidence "random" in
proc c(x?): (det y?) { ensure r: y? iff x? }
```
