A binary operator directly followed by a negation and then a space (a warning, `suspicious_unary_op_formatting`).

Example:

```fren
proc c(x: Int): (p?) { ensure r: p? iff x >=- 1 }
```

`>=- 1` reads like one operator `>=-`, but it is `>=`, whose right operand
is `-1`. `fren fix` can fix this:

```fren
proc c(x: Int): (p?) { ensure r: p? iff x >= -1 }
```
