A scrutinee of a `match` or table written the same as an earlier one (a warning, `duplicate_scrutinee`).

Example:

```fren
pub fn choose(a?, b?): Int := match a?, a? {
    true, false => 1,
    _, _ => 0,
}
```

The two columns always have the same value, so the first row cannot be
taken. The second scrutinee probably meant `b?`. Static exhaustiveness and
reachability consider every vector of values of the columns' types;
they do not establish whether the scrutinees can have different values.

The message names the first earlier scrutinee written the same. If a
row's patterns in those columns are disjoint, a note names the first such
row. There is no automatic fix: the intended scrutinee is not known.

Write the intended scrutinee:

```fren
pub fn choose(a?, b?): Int := match a?, b? {
    true, false => 1,
    _, _ => 0,
}
```
