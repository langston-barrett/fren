A code block of a Markdown spec that is never closed.

Erroneous code example, a Markdown spec:

`````markdown
# Climate control

````fren
pub proc heating(cold?): (heat?) {
    ensure rule: heat? iff cold?
}
```
`````

A block that opens at a fence of backticks closes at the next line of at
least as many backticks and nothing else, as in CommonMark. The block above
opens at four backticks, so the line of three is part of it, and so is the
rest of the file. Close the block with a fence as long as the one that
opens it:

`````markdown
# Climate control

```fren
pub proc heating(cold?): (heat?) {
    ensure rule: heat? iff cold?
}
```
`````
