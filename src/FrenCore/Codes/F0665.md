A verdict of an expectation of a trait rests on the trait's laws, whose consistency is not checked.

Erroneous code example:

```fren
set_option fren.lint.undecidable "allow" in
trait Sized {
    fn size(Self): Int

    law positive(s: Self): size(s) > 0
    law negative(s: Self): size(s) < 0

    expect anything(s: Self) { expect c: size(s) = 42 }
}
```

A trait's expectation is checked with the trait's laws among its
hypotheses. Laws that contradict each other, as `positive` and `negative`
here, make every expectation hold, whatever it claims. Fren does not yet
check that a trait's laws can hold together, so a constraint whose
verdict comes from a proof under the laws says so. A counterexample meets
the laws, so a failure has no warning. An expectation of a trait without
laws rests on none, and has no warning:

```fren
trait Sized {
    fn size(Self): Int

    expect same(s: Self, t: Self) { expect c: when s = t, size(s) = size(t) }
}
```
