A procedure that cannot be enumerated.

Erroneous code example:

```fren
type Id
fn rank(i: Id): (r: Int) { ensure positive: r > 0 }
set_option fren.evidence "enumerated" in
proc c(x: Id): (det top?) { ensure r: top? iff rank(x) = 1 }
```

Every type is enumerable (see `Reqs/Check`, "Checking by enumeration"),
but enumeration cannot yet apply an uninterpreted function with a
contract, whose postconditions constrain its interpretations, or a generic
one, each of whose instances is a function of its own; or apply a
recursive function whose body indexes a sequence, whose value out of range
it cannot give. None of the procedure's checks set to enumeration is run.
It also refuses a lowered formula deeper than 256 levels or larger than
4194304 expression nodes, before recursively compiling or inspecting it.
Expanding the procedure's variable and function types is limited to 256
levels and 262144 nodes, counting constructors and finite integer
domains together.
Have the solver or random testing check it:

```fren
type Id
fn rank(i: Id): (r: Int) { ensure positive: r > 0 }
set_option fren.evidence "solver" in
proc c(x: Id): (det top?) { ensure r: top? iff rank(x) = 1 }
```
