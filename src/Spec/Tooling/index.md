# Tooling

This part describes what the Fren tools report about a program and how
they present its source: the evidence that a check result rests on, the
diagnostics and lints, and the formatting of source text. None of it
changes what a program means. The [language part](../Language/index.md)
defines which programs are well typed and verified and what an expectation
states; this part defines the verdict that a tool gives for each and how it
is reported.

- [Evidence](Evidence.md) covers the evidence for check results.
- [Diagnostics and lints](DiagnosticsAndLints.md) covers the diagnostics
  and lints that Fren reports.
- [Formatting](Formatting.md) covers the formatting of Fren source text.
