# Each line is `linter identity` and permits one finding; the identity is the
# rest of the line. For simpNF and simpLoop it is `lemma:kind`. For unsqueezed
# it is `file:declaration: tactic`: the tactic's source text with each run of
# white space as one space, and ` #n` after the n-th call of the same text in
# the declaration, from the second. An unnamed declaration is `example@hash`
# or `instance@hash`, by a hash of its signature. No identity holds a line
# number, so moving a proof changes nothing here.
# The job prints each finding with its identity. It fails on a finding that
# is not listed and on an entry whose finding is gone, so this list only
# shrinks. Fix a new finding instead of listing it.
