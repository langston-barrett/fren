# Each line is `linter identity` and permits one finding; the identity is the
# rest of the line. For simpNF and simpLoop it is `lemma:kind`, and for a
# lemma of several rewrites `@` and a hash of the rewrite's left-hand side.
# For unsqueezed it is `file:declaration: tactic`: the declaration's name
# with its namespaces and, in brackets, its named sections, then the tactic's source text with
# each run of white space as one space, and ` #n` after the n-th call of the
# same text in the declaration, from the second. An unnamed declaration is
# `example@hash` or `instance@hash`, by a hash of its signature, with `#n`
# for the n-th of the same signature in its scope, from the second. No
# identity holds a line number, so moving a proof changes nothing here.
# The job prints each finding with its identity. It fails on a finding that
# is not listed and on an entry whose finding is gone, so this list only
